================================================================================

### 3.1 실시간 Canvas 이미지 압축 (`src/utils/imageCompressor.ts`)
- 모바일 카메라 촬영 고용량 사진이 KV/IndexedDB 용량을 초과하지 않도록 클라이언트 측 실시간 압축 수행.
- `compressImageIfNeeded(file: File, maxWidth = 1280, quality = 0.75)`:
  - 파일 타입이 `image/*`인 경우 Canvas를 사용하여 가로/세로 최대 1280px 비율 조절 후 JPEG 품질 0.75의 DataURL로 변환.
  - 비이미지 파일(PDF, ZIP, DOCX 등)은 원본 그대로 FileReader를 통해 Base64 DataURL로 변환.

### 3.2 IndexedDB 하이브리드 영속화 스토리지 (`src/utils/cardStorage.ts`)
- `localStorage` 용량 한계(5MB) 극복을 위한 IndexedDB 스토리지.
- DB명: `mhdec_file_share_db`, 버전: `1`, 스토어: `cards_store` (keyPath: `id`).
- `saveCardsToDB(cards: FileGroupCard[])`: 기존 스토어 초기화 후 전체 카드 저장. 시크릿 모드나 용량 초과 예외 발생 시 `localStorage` (`mhdec_group_cards_meta`) fallback 지원.
- `loadCardsFromDB()`: IndexedDB에서 카드 데이터 로드. 실패 시 `localStorage` fallback.

### 3.3 모바일 Pull-to-Refresh 훅 (`src/hooks/usePullToRefresh.ts`)
- `usePullToRefresh(onRefresh: () => void)`:
  - 모바일 터치 브라우저에서 화면 최상단(`window.scrollY <= 0`)에서 아래로 당길 때 브라우저 전체 새로고침(페이지 이탈)을 `e.cancelable && e.preventDefault()`로 방지.
  - 당긴 거리(pullDistance)가 60px 초과 시 `onRefresh()` 콜백 호출.
  - `{ containerRef, pullDistance }` 객체 반환.

SECTION 4. 백엔드 Cloudflare Pages Functions API 명세
================================================================================

### 4.1 메모 API (`functions/api/memos/index.ts`)
- 바인딩: `MEMO_KV` (KVNamespace), 키: `shared_memos`
- CORS & Cache Control 헤더:
  - `Access-Control-Allow-Origin: *`, `GET, POST, OPTIONS, DELETE` 허용
  - `Cache-Control: no-cache, no-store, must-revalidate`
- `onRequestOptions`: 204 Status Response 반환.
- `onRequestGet`: KV에서 `shared_memos` 로드 후 `{ memos: Array }` 반환.
- `onRequestPost`: 요청 Body `{ memos: Array }` 받아 KV에 저장.

### 4.2 파일 전송 API (`functions/api/files/index.ts`)
- 바인딩: `MEMO_KV` (KVNamespace), 키: `shared_file_cards`
- 만료 시간: `48시간` (`48 * 60 * 60 * 1000 ms`)
- CORS & Cache Control 헤더 동일 적용.
- `onRequestGet`:
  - KV에서 `shared_file_cards` 로드.
  - `uploadedAt` 기준 48시간이 지난 만료 카드는 자동으로 Purge(필터링) 후 KV에 재저장.
  - 유효 카드 목록 `{ cards: Array }` 반환.
- `onRequestPost`:
  - Body: `{ cards: FileGroupCard[], deletedCardIds?: string[], replace?: boolean }`
  - `replace: true` 시 전달받은 카드로 교체. `replace: false` 시 기존 데이터와 병합.
  - 48시간 만료 카드 자동 필터링 후 KV 저장 및 응답 반환.

### 4.3 파일 업로드/다운로드 API (`functions/api/files/upload.ts` & `[id].ts`)
- 바인딩: `FILE_BUCKET` (R2Bucket)
- `/api/files/upload`: FormData로 전달된 바이너리 파일 R2 업로드 및 `/api/files/{fileId}` 다운로드 URL 반환.
- `/api/files/[id]`: GET 시 R2에서 파일 바이너리 스트리밍 및 `Content-Disposition: attachment; filename="..."` 헤더 설정. DELETE 시 삭제 처리.

  - **개별 파일 용량 제한: 파일 당 최대 15MB 제한**. 15MB 초과 파일 존재 시 `'파일명 (용량) 파일이 15MB 용량 제한을 초과합니다.'` 경고 문구 출력 및 업로드 취소. (카드 전체 합산 용량 제한은 없음).
  - 제목 미입력 시 `"[첫번째파일명] 외 N-1개"` 자동 설정, 태그 입력 시 `#` 프레픽스 자동 부여.
- **48시간 카운트다운 타이머**: 1초 간격으로 각 카드별 남은 시간 초 단위 실시간 계산 (`X시간 Y분 Z초 남음`). 48시간 초과 시 자동 삭제.
- **카드 세부보기 모달 (`activeModalCard`) & 파일 개별/다중 관리**:
  - 카드 클릭 시 모달 오픈.
  - 모달 내 기능: 파일 전체 순차 다운로드 (`FolderDown` 아이콘, 250ms interval), 선택 체크박스, 선택 파일 다운로드/삭제, 개별 파일 다운로드.
- **iOS Safari 다운로드 최적화 & 토스트 알림**:
  - Base64 to Blob 변환 (`dataURLtoBlob`): iOS Safari 환경에서 MIME 타입을 force `application/octet-stream`으로 변환하여 탭에서 바로 열리는 현상 방지.
  - `target="_blank"` 속성 제거.
  - iOS 다운로드 클릭 시 `'📥 파일 다운로드 시도 중 ('파일' 앱 ➜ '다운로드' 폴더 확인)'` 안내 토스트 바 4초간 상단 노출.
- **검색 & 다중 카드 삭제**: 실시간 키워드 검색 및 카드 선택 일괄 삭제 기능.

SECTION 6. AI 자가 검증, 테스트 및 품질 보증 (SELF-VERIFICATION & TESTING)

개발 진행 시, AI 모델은 코드를 작성한 후 반드시 아래 **4단계 자가 검증 및 테스트 프로토콜**을 수행해야 합니다.

### [단계 1] 정적 타입 검증 및 빌드 테스트 (Static & Build Check)
1. **타입 컴파일 검사**:
   - `npx tsc --noEmit` 실행.
   - 모든 `.ts`, `.tsx` 파일에서 타입 명시가 올바른지, missing property나 any 에러가 없는지 확인.
2. **프로덕션 빌드 테스트**:
   - `npm run build` 실행.
   - Vite 빌드 과정에서 번들링 에러나 미사용 모듈 참조 에러가 발생하지 않는지 확인.

### [단계 2] 런타임 & 요구사항 체크리스트 검증 (Runtime Checklist)
- [ ] **푸터 미생성 검증**: DOM 트리 상에 `<footer>` 태그가 0개이며 푸터 영역이 전혀 노출되지 않는지 확인.
- [ ] **헤더 고정 및 탭 연결**: `Header.tsx` 높이가 50px로 고정되고 우측 액션 버튼(새로고침, 새창, 메모/일어)이 정상 동작하는지 확인.
- [ ] **디자인 시스템 준수**: Warm Beige 컬러 팔레트 (`#faf9f5`, `#efe9de`, `#cc785c` 등)가 전체 페이지에 일관되게 적용되었는지 확인.
- [ ] **15MB 제한 및 20개 제한**: '옮겨볼까?' 컴포넌트에서 파일 제한 경고 문구가 정확히 출력되는지 확인.
- [ ] **iOS Safari 다운로드 최적화**: MIME force octet-stream 및 안내 토스트 알림 로직 검증.
- [ ] **일본어 1초 터치 공개**: 플래시카드에서 1초(1000ms) 유지 시에만 발음이 노출되는지 확인.
- [ ] **로또 번호 생성 & 복사**: 5세트 색상 분기와 클립보드 복사 동작 검증.

### [단계 3] 자가 수정 및 디버깅 루프 (Self-Correction Loop)
